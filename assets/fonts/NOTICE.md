# Fonts

Both fonts are converted to vector outlines at build time (`scripts/build_readme.py`),
so the SVGs in `assets/` ship with no font files, no CDN and no external requests.

| File | Font | License |
| --- | --- | --- |
| `Silkscreen-Regular.ttf` | Silkscreen — headings, labels, buttons, tags | SIL OFL 1.1 — see `OFL-Silkscreen.txt` |
| `VT323-Regular.ttf` | VT323 — running copy (real lowercase) | SIL OFL 1.1 — see `OFL-VT323.txt` |

The `.ttf` files are only needed to rebuild the assets, not to view them.
